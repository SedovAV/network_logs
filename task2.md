## Задание: Обнаружение аномалий в сетевом трафике

### Цель работы

Научиться применять готовую ML-модель к неразмеченному сетевому трафику, самостоятельно строить признаки, интерпретировать предсказания и формулировать ограничения подхода.

### Исходные материалы

* `model.pkl` — обученная модель бинарной классификации.
* `traffic_unlabeled.csv` — датасет сетевых сессий, 1000 строк, 12 столбцов.

### Легенда классов:

* 0 — норма;
* 1 — аномалия.

### 1. Загрузка и первичный анализ

* Импортируйте `pandas`, `numpy`, `joblib`.
* Загрузите `model.pkl` и `traffic_unlabeled.csv`.

Выведите:
* размер датасета;
* типы столбцов;
* количество пропусков;
* первые 5 строк.

### 2. Предобработка

* Преобразуйте `timestamp` в `datetime`.

Заполните пропуски:

* `flags` -> пустая строка;
* `protocol` -> `'NONE'`.
Приведите protocol к нижнему регистру и сохраните как protocol_type.
3. Определение сервисов

По `dst_port` сопоставьте сервис с помощью словаря `service_map`:

* Неизвестные порты отметьте как 'other'.
* Создайте столбец service.

### 4. Построение матрицы признаков X

Сформируйте признаки:

* `src_bytes = bytes_sent`;
* `dst_bytes = bytes_received`;
* `count` — число сессий с тем же src_ip;
* `srv_count` — число сессий с той же парой `src_ip + service`;
* `same_srv_rate = srv_count / count`;
* `diff_srv_rate = 1 - same_srv_rate`;
* `dst_host_count` — число сессий с тем же `dst_ip`;
* `dst_host_srv_count` — число сессий с той же парой `dst_ip + service`;
* `serror_rate` — доля сессий с флагом ровно SYN для данного `src_ip`;
* `rerror_rate` — доля сессий с `RST` для данного `src_ip`;
* `protocol_type`, `service`;
* `duration`.

Важно: сохраните имена и состав признаков такими, какими их ожидает модель. Если модель — это `Pipeline`, категориальные признаки можно передавать строками.

### 5. Очистка признаков

* Категориальные признаки заполните `'other'` и приведите к строке.
* Числовые признаки: замените `inf / -inf` на `NaN`, затем заполните `0`.
* Приведите числовые столбцы к `float64`.
* Булевы столбцы, если появятся, переведите в `int`.

### 6. Предсказание

Получите классы:
* `pred = model.predict(X)`

Получите вероятности:
* `proba = model.predict_proba(X)`

Если классов два, возьмите `anomaly_score = proba[:, 1]`.

Добавьте в исходный датафрейм столбцы:

* prediction;
* anomaly_score.

### 7. Анализ результатов

Ответьте на вопросы и подтвердите их таблицами/расчётами:

1. Сколько записей отнесено к норме и сколько к аномалиям? Каковы доли?

2. Чем аномалии в среднем отличаются от нормы по признакам:

* duration;
* bytes_sent;
* bytes_received;
* packets_sent;
* packets_received?

3. Выведите топ-20 записей по anomaly_score. Какие порты, протоколы и флаги там преобладают?

4. Рассчитайте отношения:

* bytes_sent / bytes_received;
* packets_sent / packets_received
для классов 0 и 1. Сделайте вывод об асимметрии трафика.

5. Предложите не менее трёх идей, как улучшить признаки.
