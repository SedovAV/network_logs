## Задание

### Цель

Построить пайплайн бинарной классификации сетевого трафика,  предобработка данных, обучение нейронной сети, оценка качества, анализ ошибок и формулировка практических рекомендаций для SOC.

### Исходные данные

Файл network_logs.csv содержит 20 000 записей сетевых соединений.

### Основные признаки:

<b>числовые:</b>
* duration,
* src_bytes,
* dst_bytes,
* count,
* srv_count,
* serror_rate,
* rerror_rate,
* same_srv_rate,
* diff_srv_rate,
* dst_host_count,
* dst_host_srv_count;

<b>категориальные:</b>
* protocol_type,
* service;

<b>целевая переменная:</b>
* label (0 — normal, 1 — attack);

дополнительный столбец attack_type используется только для анализа ошибок, не для обучения.

### 1. Загрузка и первичный анализ данных

* Загрузите данные из network_logs.csv.
* Выведите размер таблицы.
* Изучите распределение attack_type и label.
* Проверьте наличие пропусков.
* Разделите признаки и целевую переменную:

```
X = df.drop(columns=["label", "attack_type"])
y = df["label"]
```

Определите категориальные и числовые признаки автоматически.

### 2. Предобработка данных

Создайте `ColumnTransformer`:
* для числовых признаков — StandardScaler;
* для категориальных — OneHotEncoder(`handle_unknown="ignore"`).
* Разделите данные на `train/test` в пропорции `80/20`.
* Используйте `stratify=y`, чтобы сохранить баланс классов.
* Зафиксируйте `random_state=42`.

### 3. Обучение нейронной сети

Соберите `Pipeline` из препроцессора и `MLPClassifier` со следующими параметрами:

```
MLPClassifier(
    hidden_layer_sizes=(32, 16),
    activation="relu",
    solver="adam",
    alpha=1e-4,
    max_iter=200,
    early_stopping=True,
    n_iter_no_change=15,
    random_state=42
)
```
Обучите модель на тренировочной выборке.

### 4. Оценка качества модели

Получите предсказания на тестовой выборке.

Выведите:
* `classification_report`;
* матрицу ошибок `confusion_matrix`;
* `ROC-AUC`;
* `accuracy` на `train` и `test`.

Сделайте вывод о наличии или отсутствии переобучения.

### 5. Анализ ошибок

Найдите `FP` (ложноположительные) и `FN` (ложноотрицательные) объекты.

Рассчитайте `recall` по каждому типу атаки:
* для каждого `attack_type` из `label == 1`;
* учитывайте только те объекты, которые попали в тестовую выборку.

Выведите:
* топ-5 худших `FN` — атак, которые модель считает нормой;
* топ-5 худших `FP` — нормальных соединений, которые модель считает атакой.

Для каждого объекта укажите:
* service;
* protocol_type;
* count;
* serror_rate;
* diff_srv_rate;
* attack_type (для FN);
* вероятность предсказания `proba`.

### 6. Визуализация

Постройте два графика:
* Тепловую карту матрицы ошибок.
* Горизонтальную столбчатую диаграмму `recall` по типам атак.
* Сохраните график в файл `errors_analysis.png`.

### 7. Рекомендации по улучшению

Предложите не менее 4 мер по улучшению модели.

Например:
* снижение порога классификации до 0.35;
* использование class_weight или SMOTE;
* добавление новых признаков;
* ансамблирование MLP с XGBoost;
* обучение на обратной связи от аналитиков SOC.
